## 一、出发点：一对一方法为什么在多对多上全线失败

在节点拆分生成的 M2M 基准（实体 = 源图节点集 × 目标图节点集，盲评协议，GT 不进预测路径）上，
库内三族 1-1 算法（一致性：IsoRank/FINAL/PARROT；嵌入：REGAL/BRIGHT/NeXtAlign/WAlign/CrossMNA；
OT 混合：JOENA）盲评 MicroF1 普遍接近零或远低于其 1-1 水平。逐一对照原论文的理论假设 +
本仓库实测，失败原因可归类，但**归类后发现它们是同一个东西的四种化身**：

1. 平衡 Sinkhorn / 双随机约束把 S 推向**置换矩阵**（Birkhoff 多面体顶点）；
2. 行级 argmax / top-k 读出**无法表达图内共指**（同图两节点属于同一实体）;
3. 对比/排序损失把同实体节点当**负样本**互相推开；
4. 逐节点对的评测协议本身假设注入性。

## 二、核心矛盾与正确学习对象

**一句话本质：排他性先验放错了层级。**
1-1 成功的前提 = 每个节点恰有一个对应（注入性）。M2M 中该前提在**节点层**崩塌——但在
**商图层**（实体对实体）重新成立：GT 实体恰好把一个源组配一个目标组。所以解法不是丢弃
排他性，而是**把它放回正确的层级**：节点层解除、组层恢复。

由此推出正确的学习对象：**等价关系（每图一个划分）+ 商图上的一对一匹配**，而非节点排列。

**奠基观察**（一切的起点，实测于 JOENA 的 S）：组内节点映射到对侧同一区域，故其 S 行
近共线（组内余弦 ~0.4），而非组内——哪怕属性完全相同且相邻——近正交（~0.0）。
**分组证据已经藏在任何训练好的 1-1 对齐器里**，不需要新模块，需要的是把读出对准正确对象。
（方法论主线：好创新不是来自设计复杂模块，而是来自认真观察模型哪里不正常——把多个表面
异常统一成一个底层机制，再围绕机制设计目标。全程每个组件对应一个实测异常，每个被拒组件
是一次被证伪的假设。）

## 三、异常 → 本质 → 解法（设计实录，13 轮）

| # | 实验中发现的问题 | 本质 | 解法（留/弃） |
|---|---|---|---|
| 1 | 固定阈值 tau 跨数据集脆弱 | 组内/跨组画像余弦分布双峰、峰位漂移 | Otsu 自适应阈值（留）；Otsu 平台偏置 bug 由单测抓出 → 平台中点修正 |
| 2 | 并查集把 A~B~C 链成一组 | 传递闭包 ≠ 等价类证据 | 平均链接质心门（抗链式，留） |
| 3 | 逐组贪心把多个源组堆到同一目标组 | 组层排他性缺失 | 商图矩形匈牙利（留）；后组级 UOT 全操作面 0.44–0.45 平台 < 匈牙利 0.677 → **排他性在组级是承重结构**（UOT 弃） |
| 4 | 证据可靠性随数据集反转（attr 在 Cora 近完美、弱属性图上 25:1 基率过合并；画像恰在平衡边际处退化）；无监督仲裁"度量乐观"（各候选优化自家信号） | 证据体制依赖，需外部合法裁判 | **训练锚点升级为组级监督**：机会校正一致率 + 0.02 容差 + 奥卡姆最粗 + ≥20 锚点守卫（6 锚点 pems08 误仲裁实测）（留） |
| 5 | Otsu 在 Cora 落在组内中位数之上（信号在，AUC 0.998，阈值错） | 无信号零分布可校准 | RMT 零分布分位数阈值候选（留）；SVD 去噪/一跳平滑（弃）；谱指纹：GD 尖峰数≈实体数、erank/n≈1=置换锁死（诊断工具，留） |
| 6 | Douban 整行跨无关节点重复（零分布 q999=1.0），全局合并精度 1.9% 无门可救 | **输入对称性**：相同 [attr, anchor-RWR] 输入 → 输出恒等（98% 节点同 attr 桶；远锚节点 RWR≈0）；损失无法分离，Sinkhorn 在 no_grad 下 | JOENA-PC：对称破缺输入（传播特征+log-度）+ 画像均匀性对比项挂 softmax 替身（留）；对称破缺占大头 0.4615→0.6295；被判死的全局候选**复活**——59.6% 组内不连通的读出天花板被打破 |
| 7 | PC 在平衡边际（airport/pems08）反而降分 | 锐化-可分组性张力的根子在**数据项的 Sinkhorn 边际** | 组级边际 GM：自举划分、每组一单位质量、rho=0.5 混合（留，pems08 1.55×）；PC-G 池化替身四集全败（弃——替身层救不了数据项） |
| 8 | 分支级锚点仲裁 seed 42 全对、多种子翻车（douban s0 自信地选错） | 锚点是被保留的 1-1 对，跨 S 比较度量的是 M2M 分支恰好让渡的 1-1 切片 | 分支仲裁**证伪撤回**；改**耦合集成**（三分支耦合平均、解码一次、无选择器）；教训：任何选择器先过多种子 |
| 9 | 均值池化稀释一对多；组内离群 | 读出细节体制依赖 | 配对多种子网格：coverage 计分（选项）、商图邻居一致性（参数默认 0）、**证据条件**离群驱逐（默认开；无守卫时在 Cora -0.043） |
| 10 | arenas 等四集"基座全灭" | **协议 bug（重大）**：m2m 的 anchor_links 本身就是原 20% 训练切分，再 train_ratio=0.2 二次切分 → 实际监督仅 ~4% | `use_full_anchor_supervision()` 修正；全部缓存/脚本迁移（_fa 标签）；此前所有数字为 4% 体制（内部一致但非论文协议） |
| 11 | 修正协议后四集仍被判"不可解" | **探测缺陷，不是数据缺陷**：probe 名单缺 PARROT + quick 预算（BRIGHT e10 held-out Hits 0.58 vs e100 0.92） | PARROT 基座四集全部复活；"拆分摧毁结构信号"的机理判断只对 BRIGHT-quick 成立 → 撤回，基准 v2 提议撤回；方法论规则：**名单不全 + 预算不诚实的探测会冤杀数据集** |
| 12 | flickr-lastfm 训练锚点 (4227,11939) 出现在测试实体 e62 | 原始数据锚点表有**重复行**，按对切分两份分落 train/test；生成器只在测试集内部去重 | 生成器跨集合端点排除 + 构建末端硬护栏（泄漏即抛错）+ 回归测试；确定性重建（实体 362→361）；两 root 复扫 18/18 干净 |
| 13 | PARROT 只是弱属性补丁吗？ | 基座应是**锚点可仲裁的一等超参**，与证据/阈值/温度同一套盲信号 | `m2m_base.py`：train_base_S + arbitrate_sharpen（raw vs softmax(S/T) 锚点盲选）；4 种子×9 集全网格：**PARROT 统一基座 7/9 直接最优** |

## 四、最终算法：PARROT + QuotientDecode（+ 可选集成精修）

```
输入: 两图 G1,G2（可无属性）、训练锚点 A（全量，修正协议）
─ 基座层 ─────────────────────────────────────────────
1. S ← PARROT(G1,G2,A)     # RWR 位置感知 + 一致性正则 OT；确定性，秒级
2. S ← arbitrate_sharpen(S) # raw vs softmax(S/T)，机会校正锚点一致率盲选
                            # （耦合型自动选 raw；嵌入余弦型自动选锐化）
─ 证据层：每侧生成候选划分 ──────────────────────────────
3. 候选 = { 画像@Otsu, 属性内聚, 零分布校准阈值, 全局候选(门控) }
   合并规则：候选边按余弦降序 + 平均链接质心门（抗链式）
─ 决策层 ─────────────────────────────────────────────
4. 证据选择：机会校正锚点一致率 + 容差0.02 + 奥卡姆最粗
   （<20 锚点回落画像对比度）
5. 商图匹配：矩形匈牙利（组级排他）+ 空候选
6. 交替精修（≤2 轮）：目标组池化列 → 画像降噪 → 重解码
7. 证据条件离群驱逐（默认开）
─ 可选精修 ────────────────────────────────────────────
8. arbitrate_base({PARROT, JOENA家族集成})   # Cora 型体制 +0.011，锚点盲选
```

**一个原则贯穿四个层级**：分组证据、合并阈值、锐化温度、基座选择，全部由同一个盲信号
（机会校正的训练锚点组级一致率 + 奥卡姆）仲裁——GT 从不进预测路径。其**有效边界**也已
测明：质量差大处可靠（17/20 格点选对），一致率饱和处失灵（pems08，见下）。

|---|---|---|---|

| cora | 0.893（attr 天花板 0.991） | 0.9805 → **0.9922**（集成，锚点可盲选中） | |
| airport | 0.27 | **0.7980** | JOENA-vanilla 分支 s42 0.827（无验证盲选择器，如实记录） |

| ppi | — | **0.9301** | |

三个可写进论文的效果声明：
1. **同一基座 + 同一读出、零逐集调参**，9 个数据集全部非平凡（0.37–0.99），其中四个曾被
   （错误地）判为不可解；
2. **弱信号放大**：弱基座数据集上盲评超过 GT 泄漏式适配器（phone-email 0.424 vs 0.230）——
   组池化聚合证据 + 匈牙利全局竞争强于逐节点 top-k，这是"商图是正确学习对象"的最硬证据；
3. **确定性与速度**：PARROT 无随机性（跨种子 std=0，集成在 pems08 ±0.056），且比三分支
   集成训练快 ~20×。

## 六、写论文可直接取用的素材

**标题方向**："The Right Level of Exclusivity: Quotient Readouts Turn One-to-One Aligners
into Many-to-Many Systems" / 中文主线："对齐即证据，划分即答案"。

**摘要骨架**：1-1 方法的四类失败是同一先验（节点级排他性）的四种化身 → M2M 的正确学习
对象是等价关系 + 商图匹配 → 分组证据已在任何 1-1 对齐器的 S 中（行共线性）→ 读出层
QuotientDecode + 训练层对称破缺/组级边际 + 基座层 PARROT，全部选择由机会校正锚点一致率
盲仲裁 → 9 数据集统一系统，弱信号处盲评反超泄漏协议。

**贡献点（4 条）**：
1. 诊断：把 1-1 方法在 M2M 上的失败统一为"排他性先验的层级错位"，每条结论实验 + 原论文理论双证；
2. 算法：QuotientDecode——把排他性放回商图层级的读出，8 个组件各对应一个实测异常；
   训练侧 JOENA-PC（输入对称性是重复行根因）与组级 Sinkhorn 边际；
3. 仲裁原则：一个盲信号（机会校正锚点组级一致率 + 奥卡姆）统一证据/阈值/温度/基座四层选择，
   并给出其有效边界（饱和失灵）的实测刻画；
4. 基准修复与协议修正：双重切分 bug、生成器跨集合泄漏 + 硬护栏、探测方法论（名单完备 + 诚实预算）。

**负结果清单（附录素材，体现严谨）**：组级 UOT（14 操作点全败→排他性承重）；PC-G 池化对比
（四集全败→张力在数据项）；分支级锚点仲裁（多种子证伪→耦合集成）；SVD 去噪、一跳平滑、
vanilla 全局候选（精度 1.9%）；max/sum/hybrid 组计分；无守卫离群驱逐（Cora -0.043）；
锚点 MRR 分支信号（反相关）。

**理论钩子**：机会校正一致率 ≈ Cohen's κ 的组级版本；平衡边际→置换锁死（Birkhoff 顶点、
BBP 相变式叙事）；GD 尖峰数≈实体数（RMT 谱指纹）；attr 过合并的 25:1 基率论证；
零分布分位数阈值（随机对画像余弦的无信号零假设）。

**可画的图**：(a) S 行共线性机制图（组内 vs 非组内余弦分布）；(b) douban 对称破缺前后
零分布 q99 1.0→0.877 + 全局候选复活；(c) arenas T 仲裁曲线（corrected 一致率 0.065→0.99
单调追踪隐藏质量）；(d) pems08 饱和散点（一致率 0.996 vs MicroF1 反序）——仲裁边界图；
(e) 损失链分解 1.000→0.981（基座）→0.959（oracle 分组）→0.851（盲）。

**局限（如实写）**：pems08 型锚点饱和盲区（集成真 +0.04 但无盲信号可选中）；<20 锚点回落
无监督仲裁在 Cora 型体制可能选错（谱指纹先验未接入）；稠密 O(n²)，max(n)≈5–6k 可行，
8 个大图（n≈24k）需稀疏化；基准为单一生成族（节点拆分），外部效度待跨源验证。

**复现**：`tests/`（48 项单测，每项对应一条设计声明）；
`run_quotient_compare.py --base PARROT`（统一系统）/ `--model auto|ensemble`（精修）；
`validate_base_selection.py` + `compare_parrot_vs_ensemble.py` + `aggregate_unified_grid.py`
（§5.13 网格）；`probe_base_aligners.py`（探测方法论文档化）。
