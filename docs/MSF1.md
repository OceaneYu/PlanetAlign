# MSF1-v2-K：双侧测试实体的成员恢复

输出名仍为 `Macro Set-F1` / `MSF1`，协议标识为 `MSF1-v2-K`（2026-10-28）。每个真实测试 unit 等权，分母固定为 K。此前目标侧 MSF1，以及双侧但使用 `max(K,L)` 的版本，均不能直接与本版比较。旧实验文件不重写；用相同预测重评并保存到新文件。

## 非重叠与重叠模式

- 默认 `allow_overlap=False`：GT 和整份预测的每侧节点最多属于一个 unit。预测违反时抛出 `InvalidPredictionError`（`ValueError` 子类），错误包含图侧、节点和冲突组编号。**先验证全部预测，再筛选测试范围**，训练／背景节点跨组复用同样非法；不删除、合并或修补预测。GT 违反时报告配置错误。
- 一个 unit 内的重复成员按集合处理；两个非空 unit 完全重复则非法。多个全空预测组不违反节点归属约束，评分时忽略。
- 重叠 Benchmark 必须显式传 `allow_overlap=True`；正式实验脚本依据 GT 文件的 `metadata.overlap_ratio` 选择模式，不根据预测是否重叠自动放宽约束。重叠模式保留原有的重叠成员与重复 unit 语义，**不声称解决重复预测获益问题，也不与非重叠结果混用**。其提交约束需要单独定稿。
- `macro_set_f1()`、`macro_f1_score()`、`many_to_many_scores()`、`evaluate_predictions()` 和 `evaluate_blind()` 均支持该关键字。校验随 MSF1 计算执行；只请求其他指标时，不改变其既有行为。

## 评分范围

当前两套生成 Benchmark（`data/m2m_no_overlap`、`data/m2m_overlap_0.05`）共 36 个数据集已核查：GT 完整列出构建器选中的测试实体及全部拆分成员，和保存的训练锚点无节点交集。

依据为 [many2many_builder.py](../PlanetAlign/utils/many2many_builder.py) 的 `build_many_to_many_benchmark()`：筛选测试锚点、排除训练节点冲突，再将 `group_src[u]`、`group_tgt[v]` 全部写入 `entities`。重叠设置只让已有测试成员加入另一测试实体，不扩大测试节点范围。

GT 覆盖的是这个 Benchmark 筛选后的测试实体，不是全图，也不保证保留原始测试锚点的每一行。`.pt` 的 `anchor_links` 是训练监督；`Dataset.test_data` 是这些锚点的再次划分，不能当作本协议的测试节点集合。

分别取 GT 的源侧、目标侧节点并集作为双侧测试范围。**只要预测组含任一同侧测试节点，就让整个组参与评分，并保留全部成员。**

- 纯训练组、纯未标注背景组不参与，不增加分母；没有完整真值，不能将它们直接判错。
- 与测试成员混组的训练、背景或其他错误成员全部保留，针对匹配到的真实实体计为 FP。
- 单侧预测组只要触及测试范围就保留，但所有预测组都不改变固定分母 K。
- 不根据 GT 删除组内成员，不修改原始预测或解码器输出。
- GT 不完整的新数据不能直接套用这个测试范围，需要先明确完整标注的评估范围。

## 公式及新旧差异

每个 unit 是带图侧标记的集合：

`U = {(src, s): s ∈ S} ∪ {(tgt, t): t ∈ T}`。

源图节点 7 和目标图节点 7 是两个不同成员。每对真实组 G、参与评分的预测组 P 的分数为：

`F1(G,P) = 2 × |G ∩ P| / (|G| + |P|)`。

对真实组与参与评分的预测组做**最大总 F1 的全局一对一匹配**，未匹配真实组贡献 0：

`MSF1 = (1/K) × Σ_{i=1}^K F1(G_i, matched_prediction_i)`。

未匹配真实 unit 的 F1 为 0；K 为 0 时约定得 0。每个真实 unit 权重相同，与成员数无关。L 只记录参与预测组数，不进入分母。未匹配预测不直接追加惩罚；合法拆分和合并通过组对 F1、以及一对一匹配中的漏恢复扣分。它不是 Node-Pair F1，成员恢复分数不能解释成跨图节点对应关系的正确比例。

| 项目 | 旧目标侧 MSF1 | MSF1-v2-K |
|---|---|---|
| 比较成员 | 目标侧 `tgt` | 带侧标记的 `src` 与 `tgt` |
| 实体对应 | 正常评估入口先按重叠贪心对应编号 | 指标内部最大化总双侧 F1，不依赖编号或遍历顺序 |
| 分母 | 真实实体数 | 固定真实测试 unit 数 K |
| 未匹配额外组 | 不直接计入 Set-F1 | 不改变分母；非重叠模式禁止节点跨组复用 |
| 范围外预测 | 没有独立的范围协议 | 纯范围外组忽略；混入参与组的范围外成员计 FP |

例如真实 A=`src{1}, tgt{5}`：预测 `src{2}, tgt{5}` 的新版 F1 是 `2×1/(2+2)=0.5`；旧版经编号对应后只看目标侧，可以得 1。预测 `src{1,99}, tgt{5}` 的新版 F1 是 `2×2/(2+3)=0.8`，99 即使是训练或背景节点也不会被过滤。另加一个完全不涉及测试节点的训练组，不改变这两个分数。

一个真实组有 4 个成员，拆成两个各含 2 个成员的预测组：最佳组对 F1 为 `2/3`，K=1，因此 MSF1 为 `2/3`。反向将两个等大的真实组合并，只有一个真实组获得 `2/3`，另一个为 0，K=2，因此 MSF1 为 `1/3`。这种不对称来自以真实 unit 为平均对象的 Macro 定义。

## 边界规则

- 空预测、没有参与评分的预测组、空 GT 字典均得 0；双方都空也约定为 0，不代表成功恢复了实体。
- 这些空输入规则仅指 MSF1-v2；同时请求其他指标时，它们原有的边界限制不变。单独验证空 GT 可用 `evaluate_predictions({}, {}, metrics=["MSF1"])`。
- 空预测组不触及测试范围，因此忽略。GT 中全空 unit 贡献 0，但仍计入真实组数；当前生成 Benchmark 没有这种 GT unit。
- 非重叠模式拒绝重复非空预测组，不通过分数惩罚或静默去重处理。重叠模式不提供这一保证：两个等大真实组 A、B，输出一次 `A∪B` 得 `1/3`，输出两个相同副本得 `2/3`。
- `src` / `tgt` 缺失时视为空侧；仅有单侧成员的 unit 可以得到部分分数。
- 本函数没有图节点总数，不能验证节点是否真的存在于图中。参与组中的未知编号也保留为错误成员，不会静默删除。
- 显式重叠模式不给 GT 中重叠成员指定唯一归属；每个完整真实 unit 独立参与一对一实体匹配。

## 指标含义和适用边界

适用于完整标注测试 unit 的双侧成员恢复，范围为 `[0,1]`。在非空、非重叠 GT 和合法预测下，1 表示所有测试 unit 都被完整且准确地恢复；真实 unit 缺失贡献 0。

成员按节点等权：两侧人数不等时，成员较多一侧对组对 F1 影响更大。只恢复源侧也可能得到较高部分分数，例如真实 `src{1},tgt{5}` 预测 `src{1},tgt{}` 得 `2/3`。本指标不要求两侧各占一半，也不等价于跨图节点对正确率。纯范围外预测不评分、未匹配预测不额外增加分母，是该评估范围与 Macro 定义的边界。

## 无需训练的重评分

`scripts/rescore_msf1.py` 读取已保存的预测，接受原始 entity map、`{"entities": ...}` 或 `{"method": entity_map, ...}`。非法预测记录为 `status="invalid_prediction"`，不输出数值分数，继续处理其他方法并以非零状态退出；输出文件必须是新文件。

```bash
python -m scripts.rescore_msf1 \
  --gt data/m2m_no_overlap/douban_m2m_gt_many2many.json \
  --predictions logs/m2m_diag/gadl_m2m_backbone_douban_no_overlap_seed42_predictions.json \
  --out logs/msf1_rescore_new/douban.json
```

重叠 Benchmark 额外传 `--allow-overlap`，且必须与 GT 元数据一致。结果包含协议标识、模式、输入 SHA-256、K/L、分数和同一预测采用旧双侧 `max(K,L)` 分母的对照值；这个对照值不是历史目标侧 MSF1。

## 代码路径及隔离

[core.py](../PlanetAlign/m2m/core.py) 的 `evaluate_predictions()` 将原始预测交给 MSF1；另将原有贪心编号适配结果交给 Micro-SF1、AUIS、AUCS。`match_entities=False` 只改变其他指标的编号处理，不改变 MSF1-v2 的全局匹配。

[many_to_many.py](../PlanetAlign/metrics/many_to_many.py) 的 `many_to_many_scores()` 对所有 MSF1 别名使用原始预测。直接调用时，其余指标仍按传入字典评分；需要统一编号适配时使用 `evaluate_predictions()`。

[metrics_MSF1.py](../PlanetAlign/metrics/metrics_MSF1.py) 的 `macro_set_f1()` 返回分数及参与、忽略、未匹配真实/预测组数；`macro_f1_score()` 返回分数标量。`MissingPredEntities` 现在指未与参与预测组匹配的真实 unit 数，`ExtraPredEntities` 指未匹配的参与预测 unit 数。旧 `key="tgt"`、`MacroPrecision`、`MacroRecall` 接口删除，避免把目标侧宏平均和新版指标混用。

实现仅为有交集的组对保存 F1。为每个真实组提供零分虚拟组，使用 SciPy 的稀疏全局匹配最小化固定匹配数量下的 `2-F1` 成本，与最大化总 F1 等价，避免上万个实体构成稠密矩阵。单位按成员排序、用 `fsum` 汇总，实体 ID 和字典顺序不影响分数。

`OracleSrc+GT-K-Target-MSF1` 仍是给定真实源组和目标数量后的**目标侧诊断**，保留旧定义，不是这里的 MSF1-v2。Micro-SF1、AUIS、AUCS 的公式及预测算法均未修改。

测试例子见 [test_macro_set_f1.py](../tests/test_macro_set_f1.py)。

相关回归测试 **101/101 通过**，其中 400 个随机小例与独立穷举最优匹配对照。36 套 GT 的完美预测均为 1、空预测均为 0；18 套非重叠数据通过严格归属校验，18 套重叠数据使用显式重叠模式。[测试记录](../benchmarks/msf1_review_20261028/tests.json)、[边界与小例结果](../benchmarks/msf1_review_20261028/property_checks.json)。

|---|---|---:|---:|---:|---:|
| Douban / GADL | 已保存预测 | 895 | 651 | 0.337371 | 0.337371 |
| Douban / JOENA | 已保存预测 | 895 | 669 | 0.468627 | 0.468627 |

全部预测通过非重叠校验，无需重训。前三份 PARROT 缓存校验了数据文件 SHA-256；Arenas 使用历史文件名标识的缓存，重新执行只依赖训练锚点的温度选择。分数变化仅来自同一预测的分母变化，不表示模型改进。[已保存预测重评分](../benchmarks/msf1_review_20261028/douban_saved_predictions.json)、[缓存重解码记录及新预测路径](../benchmarks/msf1_review_20261028/cached_parrot.json)。

另实测了退化输出：仅按图节点总数，为每个节点输出一个单侧 singleton unit，不提供任何跨图对应，在 18 套非重叠数据上仍得 **0.573063–0.581190**。[完整结果](../benchmarks/msf1_review_20261028/singleton_baseline.json)。源分组完全正确、目标全空的 GT 受控诊断为 **0.654015–0.663276**；后者使用 GT 源分组，不是模型成绩。

结论：本实现正确评价既定的非重叠群组成员恢复目标，可作为该维度的正式指标；中等分数允许缺失跨图对应，不能直接视为“已正确对齐的比例”或作为完整对齐成功的唯一判据。这是成员 F1 定义的部分计分性质。重叠模式仍需单独确定重复提交约束，尚不建议据此宣称重叠 Benchmark 指标已经定稿。
