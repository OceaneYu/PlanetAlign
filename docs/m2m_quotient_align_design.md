# QuotientDecode：由"核心矛盾"推出的多对多图对齐算法
### 设计、实现与盲评验证

> 配套代码：[`PlanetAlign/m2m_quotient.py`](../PlanetAlign/m2m_quotient.py)（算法）、
> [`tests/test_m2m_quotient.py`](../tests/test_m2m_quotient.py)（10 项单元测试）、
> [`scripts/run_quotient_compare.py`](../scripts/run_quotient_compare.py)（对照实验）。
> 全部数字可由对照脚本复现，原始输出在 `logs/m2m_diag/quotient_compare_*.json`。
> 前置分析见 [m2m_why_one_to_one_fails.md](m2m_why_one_to_one_fails.md)。
> 实验配置：seed=42、train_ratio=0.2、JOENA quick（10 epochs）；单种子定性验证，非调参终榜。

## 摘要

沿"观察异常 → 统一机制 → 围绕机制设计目标"的路线，我们把一对一（1-1）图对齐在多对多（M2M）上的失败
归结为一个矛盾：**方法在节点层强加排他性先验，而任务的本质是实体层的等价类**。据此设计 QuotientDecode：
在**任意** 1-1 对齐器产出的相似度矩阵 `S` 之上，(i) 用对齐画像（S 的行/列）解码每图的等价类，(ii) 在**商图**上
做全局一对一匹配——让排他性先验回到它正确的层级，(iii) 用**训练锚点升级为组级监督**来仲裁分组证据。
在同一个 JOENA `S` 上只换读出（受控实验），盲评 MicroF1：Douban **0.318 → 0.462**（+45%，此前最优读出），
Cora **0.991 → 0.9925**（超过 attr 天花板），Airport **0.264/0.747 → 0.831**，PeMS08 **0.315 → 0.447**——
四种典型体制下同时最优；每个组件都有消融支撑。随机矩阵理论（RMT）的复审（§5.5）贡献了谱指纹诊断与
零分布校准阈值，证伪了三条歧路，并测出读出层的信息论天花板（Douban 59.6% 组图内不连通），其根因是
**输入对称性**：相同的 `[属性, 锚点RWR]` 输入使无关节点的耦合行永远重复。训练侧修复 **JOENA-PC**（§5.6：
对称破缺位置特征 + profile 均匀性对比项）溶解重复行、令被判死的全局候选复活，Douban 升至 **0.677**
（最初基线的 2.13×）；配合对齐器级锚点仲裁（auto），四数据集无一回退。同一个盲仲裁原则——机会校正
锚点一致率 + 奥卡姆——贯穿分区证据、阈值、对齐器三层。

## 1. 设计原则（每条都从矛盾直接推出）

| # | 原则 | 来自哪条失败分析 |
|---|------|----------------|
| P1 | **学习对象 = 等价关系**：输出是"每图一个划分 + 划分间匹配"，不是节点耦合 | 表示缺口：`S∈R(n1×n2)` 无图内块，49%（Douban）实体需图内共指 |
| P2 | **证据用模型已有的**：分组信号取自 S 的行共线性，不新增表示学习 | 异常 4/5：嵌入正则是 no-op；组员 S 行 cos≈0.4、非组员 ≈0.0 |
| P3 | **排他性放回正确层级**：商图上每组一个单位，做全局一对一 | 真值实体 = 一个源组 ↔ 一个目标组；节点层的禁令在组层是正确先验 |
| P4 | **监督升级而非泄漏**：只用训练锚点（任务给定监督）做读出的模型选择；实体真值永不进入预测路径 | 评测泄漏 4.7× 的教训；困难表第 6 行"锚点升级为组级监督" |

## 2. 形式化

给定 `S∈R(n1×n2)`（任意 1-1 对齐器的输出）与两图 `G1,G2`，求
**划分** `P1 = {A_1,…,A_g1}`（G1 的等价类）、`P2 = {B_1,…,B_g2}`，以及**部分匹配** `M ⊆ P1×P2`（每组至多用一次）。
预测实体即 `{src: A_a, tgt: B_b}`，`(A_a,B_b)∈M`。这把 M2M 归约为：

```
M2M(G1, G2)  ≡  划分(G1) + 划分(G2) + 一一对齐(商图 Q1, Q2)
```

商图上组质量为"每实体一个单位"（与组大小无关）——因为基准里每个实体恰是一个源组配一个目标组，
一一先验在此层级重新成立。

## 3. 算法：QuotientDecode

六个组件，每个对应一条已诊断的困难（〔实〕=本仓库实验证据，〔理〕=方法学依据）：

| 组件 | 做什么 | 依据 |
|------|--------|------|
| ① 画像聚类 | 候选=图内相邻对（生成器性质②），合并证据=行画像余弦 | 〔实〕组内/组外 cos 0.4 vs 0.0；〔理〕组员与对图同区域对齐 ⇒ 行共线 |
| ② Otsu 自适应阈值 | 阈值取相邻对余弦分布的 Otsu 分割点（平台取中点），逐图逐轮自适应 | 〔实〕固定 τ=0.1 在 Douban 损失 0.055 MicroF1；〔理〕组内/组外双峰分布的经典分割 |
| ③ 防链式合并 | 候选边按余弦降序处理；合并需两组**质心**余弦也过阈（平均连锁门） | 〔实〕Douban 消融 +0.055；〔理〕并查集传递性会把 A~B~C 链成一团 |
| ④ 商图 Hungarian | 组级池化分数 `T(a,b)`，矩形指派全局一对一，低分留空 | 〔实〕Douban +0.058、Cora +0.002；〔理〕商图近双射 ⇒ 全局指派是 MAP 读出 |
| ⑤ 锚点仲裁的证据选择 | 每侧候选 {profile@Otsu, attr 内聚}，按**机会校正锚点一致率**选组合，平票取**最粗**分区（奥卡姆） | 〔实〕Cora +0.100（0.893→0.9925）；〔理〕见 §4 |
| ⑥ 交替细化 | 用对侧组把画像从 n 维池化到 g 维（去噪），重解码重匹配至分区不动点（≤2 轮） | 〔实〕Douban +0.004（最弱组件，如实报告）；〔理〕坐标上升式交替 |

可选扩展：**模糊边界展开**（`overlap_expand_tau`）——匹配后允许节点以画像-质心余弦加入一个额外实体，
对应生成器的 `overlap_ratio`；默认关闭（见 §5 的权衡）。

伪代码：

```
QuotientDecode(S, G1, G2, anchors):
  profiles ← (S 的行, S 的列)
  repeat ≤ max_iters:
    每侧生成候选分区: profile@Otsu(防链式), attr 内聚(若有属性)
    (P1, P2) ← argmax 机会校正锚点一致率; 平票中取组数最少者   # §4
    profiles ← 按对侧分区池化(S)                               # n 维 → g 维去噪
  until 分区不动
  T ← 组级池化分数(S, P1, P2);  M ← Hungarian(T, 阈值)
  return {(A_a, B_{M(a)})}
```

复杂度：解码 O(|E|·n)（画像余弦）+ O(n1·n2)（池化）+ LAP(g1×g2)；
Douban 全程 0.5 s、Cora 1.3 s（JOENA 训练之外）。

## 4. 仲裁器的三次迭代（异常驱动的设计实录）

这一组件经历了两次失败，修正过程本身印证了方法论，如实记录：

1. **画像对比度仲裁（失败）**：以"组内相邻对画像余弦 − 组外"选分区。Cora 上选错（0.893 vs attr 的 0.991）。
   **异常的机制**：候选之一（profile 分区）正是按该信号构造的——度量乐观偏差；更深层，Cora 两侧规模相近
   （3595≈3553），OT 质量守恒把 `S` 锁成近置换，**组员被迫指向不同目标列，画像共线性信号本身退化**
   （Douban 上 n1/n2≈2.9，列容量允许组员共享目标列，信号才存在）。这是对"边际约束禁令"的一个新佐证。
2. **原始锚点一致率仲裁（失败）**：以"匹配后锚点两端落入同一实体的比例"选分区。Cora 上**双双饱和为 1.0**
   ——锚点恰是被保留的 1-1 节点对，携带的 M2M 结构最少；而大团块又能靠"吞掉锚点"虚高。
3. **机会校正 + 奥卡姆（采用）**：一致率减去按组大小计算的随机命中期望
   `raw − mean(|matched tgt group| / n2)`（消除团块作弊）；校正后打平（容差 0.02）的候选中取**组数最少**的分区对
   （能解释锚点的最少实体数）。Cora 上 attr 与 profile 校正后同为最优，attr 更粗 → 被选中（0.9925）；
   Douban 上 attr 团块被机会项压低 → profile 胜出（0.4615 不回退）。

单元测试 `AnchorArbiterTest` 固化了这一行为：画像无信息 + 属性有信息 + 锚点在手 ⇒ 必选 attr。

## 5. 实验

受控设定：**同一个 JOENA `S`（alpha=0.7，10 epochs，seed 42），只换读出**；全部盲评（预测路径不见实体真值）。

**主表（盲评，MicroF1 / MSF1 / ACS）**

| 读出 | Douban | Cora |
|------|--------|------|
| attr-blind（此前最优，m2m_blind 默认） | 0.318 / 0.305 / 0.365 | 0.991 / 0.993 / 0.974 |
| profile-greedy（= JOENAGroupDecode） | 0.344 / 0.317 / 0.376 | 0.936 / 0.956 / 0.795 |
| **QuotientDecode** | **0.462 / 0.388 / 0.429** | **0.9925 / 0.994 / 0.975** |
| QuotientDecode + overlap(.35) | 0.478 / 0.407 / 0.472 | 0.993 / 0.995 / 0.983 |

相对提升（MicroF1）：Douban 对 attr-blind **+45.3%**、对 JOENAGroupDecode **+34.3%**；Cora 反超 attr 天花板 +0.17pt
（profile-greedy 则落后它 5.5pt）。

**消融（MicroF1；每次去掉一个组件）**

| 变体 | Douban | Cora | 结论 |
|------|--------|------|------|
| 完整 | 0.4615 | 0.9925 | — |
| − Hungarian（改贪心） | 0.4040 | 0.9908 | 全局指派 +0.058 / +0.002 |
| − 防链式 | 0.4063 | 0.9925 | +0.055 / 0 |
| − Otsu（固定 τ=0.1） | 0.4063 | 0.9925 | +0.055 / 0 |
| − 证据选择（仅 profile） | 0.4615 | **0.8926** | Cora 上 +0.100，决定性 |
| − 锚点（对比度仲裁回退） | 0.4615 | **0.8926** | 锚点仲裁是证据选择生效的前提 |
| − 迭代（1 轮） | 0.4573 | 0.9925 | 仅 +0.004，最弱组件 |

两数据集的组件贡献**互补**：Douban 靠 ②③④（画像侧精修），Cora 靠 ⑤（证据仲裁）——与机制解释一致
（Douban 画像信号强、Cora 画像信号被平衡边际抹掉）。

**overlap 扩展的权衡**：Douban（overlap_ratio=0.05）上 MicroF1/ACS/SGS 全升（SGS 0.370→0.674），
但 EGS 0.439→0.104——二次成员让真值组暴露于更多预测簇。Cora（无 overlap）上无害（0.9925→0.9930）。
故默认关闭，仅在已知有模糊边界的数据上开启。

## 5.5 随机矩阵理论（RMT）视角：两个采纳、三个证伪、一个天花板

以 RMT 视角重新审视 `S`（诊断脚本 [`scripts/diagnose_rmt.py`](../scripts/diagnose_rmt.py)，
输出 `logs/m2m_diag/rmt_diagnosis.json`；真值只用于诊断曲线，不进算法）：

**谱指纹（采纳为诊断）**。对 `S` 做 SVD，以 Gavish–Donoho 阈值数"信号尖峰"：
- Douban：**尖峰 663 vs 真实实体 895**（同数量级——谱在"数实体"），有效秩 erank=167 ≪ 1460；
- Cora：**尖峰 0、erank=3060（近满秩）、stable rank=1400**——置换锁死的定量指纹：耦合近等距、谱平坦，
  组信号在能量意义上不可见。这把 §4-1 的机制解释从推断升级为测量。

**零分布校准阈值（采纳为候选证据 ⑤′）**。随机节点对的画像余弦构成"无信号零分布"，其上分位数即校准的
合并阈值。测量动机：Cora 上 Otsu 落在 0.43–0.46，**高于组内中位数 0.346**——信号其实在（组内 vs 组外
AUC=0.998），是阈值选错了；零分布 q999=0.066 恰在正确区间。实现为 `profile-null` 候选（含退化守卫：
零分布重尾至 >0.9 时弃用，如 Douban q999=1.0），交由锚点仲裁。airport 上该族候选与 Otsu 同优，
pems08 上由回退仲裁正确选中 profile。

**三个证伪（省下的弯路，全部有测量）**：
1. **SVD 去噪**：Douban 分离度不变（S 本就低秩）；Cora 灾难性退化（尖峰=0 ⇒ 秩-1 截断，AUC 0.998→0.85）。
2. **目标图一跳平滑**：本想修复置换锁死（组员指向相邻目标），实测两侧 cross 中位数被抬高
   （Douban tgt 0.001→0.302），AUC 全面下降。
3. **全局候选（修不连通组）**：属性桶 ∩ 画像近重复（≥0.98）∩ 枢纽防护的非相邻候选，**精度仅 1.9%**
   （154/7917 真对）；挖掉 top-1 列后假对余弦仍 0.9999（整行全局重复，正是零分布重尾预言的），
   行尖锐度门控最好也只有 17% 精度 @ 30/154 召回。仲裁器在启用时也正确拒绝了它（锚点一致率
   0.34 vs 0.52）。保留实现（默认关）作为记录。

**一个天花板（本轮最重要的结构性发现）**。Douban 源侧 **59.6% 的多节点组在图内部不连通**
（225/906 节点经组内边不可达）——邻接受限合并的硬上限；而识别非相邻兄弟所需的信息在
S（整行重复）、属性（907 人大桶）、结构（生成器把邻居不相交地分拆）三处**都不存在**。
突破只能来自训练时目标（把重复行分开的 profile 对比损失），读出层到此为止。

**锚点稀缺守卫（pems08 的教训）**。仅 6 个训练锚点时一致率估计是噪声，仲裁选错
（0.390 < 纯 profile 的 0.447）；锚点数 < 20 时自动降级到对比度回退，pems08 修复为 0.4467，
其余数据集不受影响。

**四数据集泛化（盲评 MicroF1，同一 JOENA `S` 只换读出）**

| 读出 | Douban | Cora | Airport | PeMS08 |
|------|--------|------|---------|--------|
| attr-blind | 0.318 | 0.991 | 0.264 | 0.315 |
| profile-greedy（JOENAGroupDecode） | 0.344 | 0.936 | 0.747 | 0.189 |
| **QuotientDecode（最终版）** | **0.462** | **0.9925** | **0.831** | **0.447** |

四个数据集覆盖四种典型体制：模糊边界+规模悬殊（Douban）、强属性+置换锁死（Cora）、
弱属性 4 维（Airport，attr 证据崩溃而画像证据强）、微型图+稀缺锚点（PeMS08）。
最终版在全部四种体制下同时是最优读出——此前没有任何单一证据/阈值方案能做到。

## 5.6 训练侧：JOENA-PC（突破读出天花板）

§5.5 测出的天花板宣判"只改读出到此为止"，本节把修复前移进训练（实现
[`PlanetAlign/m2m_contrastive.py`](../PlanetAlign/m2m_contrastive.py)）。

**根因（比"缺个损失项"更深）**。JOENA 的输入是 `[属性, 锚点RWR]`。Douban 上 98% 节点与他人共享完全相同的
属性行（最大桶 907 人），而远离全部 44 个训练锚点的节点 RWR 亦近零——**输入完全相同 ⇒ MLP 输出永远相同 ⇒
耦合行永远重复**，梯度也相同，任何损失都无法分开它们。整行重复（null q999=1.0）与 59.6% 不连通天花板由此而来。
另外 Sinkhorn 在 `no_grad` 下运行，S 本身不可微——对比项须加在可微替身上。

**两条腿的设计**：

1. **打破输入对称**：拼接可观测位置特征——一跳均值传播属性 $\hat{A}x$（无关孪生的邻居不同、真兄弟的邻居
   同源于一个原节点）、传播 RWR、log 度数。
2. **profile 对比项**（作用在可微替身 $p_i=\mathrm{softmax}(z_i/T)$，$z=\mathrm{out}_1\mathrm{out}_2^\top$ 即耦合行的驱动量）：
   *均匀性*——随机对的 $p$ 行推向正交（均方余弦；随机对以概率 ≈1 非共指，即 Wang–Isola 的 alignment-uniformity
   分解中的均匀性项）；*自举正对*（可选）——耦合行余弦 ≥0.95 的相邻对拉近。

**Douban 消融矩阵**（quotient 读出，盲评 MicroF1 / Hits@1）：

| 配置 | MicroF1 | Hits@1 |
|------|---------|--------|
| 基线 JOENA | 0.4615 | 0.4525 |
| PC 仅对称破缺（λu=0, λa=0） | 0.6295 | 0.5056 |
| PC λu=1, λa=0 | 0.6343 | 0.5056 |
| PC λu=1, λa=1（冻结配方） | 0.6329 | 0.5112 |
| PC λu=10, λa=1 | 0.6258 | 0.4888 |
| **PC λu=1, λa=1 + 全局候选** | **0.6768** | 0.5112 |

三个要点：(i) **对称破缺独占大头**（+0.168），且 1-1 的 Hits@1 同时提升——位置特征对齐本身也受益；
(ii) 均匀性小幅加成、λ=10 过犹不及；(iii) **零分布主体溶解**（随机对 q99 由 1.0 → 0.877）后，
§5.5 判死的全局候选**复活并赢得锚点仲裁**（+0.044）——"读出证据的可用性取决于表示质量"这条链闭环。

**体制依赖与对齐器级仲裁**。冻结配方泛化：Cora 0.9925→0.9933（无损）；但 Airport 0.831→0.757、
PeMS08 0.447→0.418——平衡边际（$n_1\approx n_2$）下锐化 S 趋向置换，削弱画像可分组性（Cora 机制重现）。
解法不是手工挑模型，而是把仲裁再上提一层：`entity_anchor_agreement` 以机会校正锚点一致率为**最终实体图**打分，
在 JOENA 与 JOENA-PC 两个分支间盲选（<20 锚点保守取基线）。四个数据集全部选对
（锚点一致率排序与隐藏的盲评质量一致）：Douban 选 PC（0.522>0.499）、Airport 选基线（0.957>0.914）、
Cora 平票取 raw 更高者、PeMS08 走保守规则。

**最终系统表（盲评 MicroF1；seed-42 单种子演进 + 多种子定稿见 §5.8）**

| 系统 | Douban | Cora | Airport | PeMS08 |
|------|--------|------|---------|--------|
| attr-blind（最初基线，s42） | 0.318 | 0.991 | 0.264 | 0.315 |
| JOENAGroupDecode（s42） | 0.344 | 0.936 | 0.747 | 0.189 |
| QuotientDecode（JOENA，4 种子均值） | 0.435 | 0.992 | 0.826 | 0.505 |
| **ensemble（最终系统，4 种子均值）** | **0.639** | **0.992** | 0.768 | **0.651** |

Douban 全程（多种子口径）：0.32 → 0.44 → **0.64**；PeMS08：0.32 → 0.51 → **0.65**。
仲裁原则在**分区证据层与阈值层**成立（同一 S 内比较，锚点度量分组质量）；在**对齐器层**被多种子证伪
（§5.8，不同 S 的 1-1/M2M 质量解耦），由无选择器的耦合集成接任。

## 5.7 训练侧二：组级 Sinkhorn 边际（保留）

PC-G 的证伪（§7-1）把矛头指向数据项本身，本节直接改它（实现于
[`m2m_contrastive.py`](../PlanetAlign/m2m_contrastive.py) 的 `JOENAPC(group_marginals=True)`，
不动上游 `algorithms/joena`）：**训练中每轮从当前 S 自举分区（同读出的画像聚类），把 Sinkhorn 边际从
"每节点 1/n" 改为 "每组一个单位、组内均分"，与均匀边际按 ρ 混合**（默认 ρ=0.5，warmup 3 轮）。
这在组级消除 k-对-m 的质量错配：实体的 k 个源节点合计一个单位，可整体送进对面 m 个节点的目标组。

**实测（quotient 盲评 MicroF1）**：

| 配置 | Douban | Cora | Airport | PeMS08 |
|------|--------|------|---------|--------|
| vanilla JOENA | 0.4615 | **0.9925** | **0.8306** | 0.4467 |
| PC | 0.6768 | 0.9933 | 0.7574 | 0.4175 |
| **PC+GM(ρ=0.5)** | **0.6917** | 0.9356 | 0.7741（ρ=0.7: 0.7861） | 0.6667 |
| GM-only（无对比项/无对称破缺） | 0.4923 | — | 0.7605 | **0.6921** |

四个发现：(i) **Douban 新高 0.6917**（GM 叠加在 PC 上再 +0.015）；(ii) **PeMS08 爆发**：GM-only 0.6921 =
vanilla 的 1.55×，且 Hits@1 同升（0.57→0.77）——小平衡图上组级边际正中病根；(iii) Cora 回退（0.9356，
自举分区在置换锁死体制下质量差 → 边际被带偏），Airport 改善但未反超（0.786 < 0.831）——两处均由 auto
仲裁保护；(iv) 收益来源分解：Douban 靠 PC（GM 只加成），PeMS08 靠 GM 本身。

**三分支 auto 仲裁**。分支集 {joena, joena-pc, joena-pc-gm}；规则：机会校正一致率容差 0.02 内取并列集 →
严格 raw 最大 → 仍全平取最精化分支（此步只在 Douban 触发，pc 与 pc-gm 的 corrected/raw 双双打平，
锚点真分不开时偏向训练先验更强者，+0.015）。四数据集选择全部正确：Douban→pc-gm、Cora/Airport→joena
（corrected 边际决定性）、PeMS08→保守 joena。

**诚实的缺口**：PeMS08 只有 6 个训练锚点，组级一致率排错（0.4928 vs 0.4906）、节点级训练锚 MRR 亦被
证伪（反相关——它度量 RWR 地标行锐度，恰是 GM 为分组让渡之物）。**锚点稀缺体制暂无已验证的盲分支仲裁
信号**，auto 保守回退 joena（0.4467），GM 的 0.69 作为手动可选（`--pc-group-marginals`）记录在案。

## 5.8 多种子验证：分支仲裁被证伪，耦合集成接任（关键修正）

以上 §5.6/§5.7 的分支仲裁结论基于 seed 42。补跑 seeds 0/1/2（4 种子 × 4 数据集 × 3 分支，
日志 `logs/m2m_diag/multiseed/`）后，结论需要修正：

**分支质量稳健，分支仲裁不稳**（quotient 盲评 MicroF1，4 种子均值±std）：

| 分支 | Douban | Cora | Airport | PeMS08 |
|------|--------|------|---------|--------|
| joena | 0.435±0.030 | **0.992±0.001** | **0.826±0.007** | 0.505±0.047 |
| joena-pc | **0.630±0.032** | 0.960 | 0.757±0.007 | 0.444±0.143 |
| joena-pc-gm | 0.603±0.090 | 0.954 | 0.771±0.003 | **0.658±0.024** |

每个数据集都有一个跨种子稳定的最优分支（Douban→pc、Cora/Airport→joena、PeMS08→gm）——**训练侧
改进是真实的**。但锚点一致率的分支级仲裁：Douban 4 选 1、Cora 4 选 3、PeMS08 0/4（保守规则）、
Airport 4/4。更糟的是 Douban s0 上它**自信地选错**（joena 一致率 0.636 vs gm 0.477，实际解码差 0.15）
——偏差是结构性的：锚点恰是被保留的 1-1 对，分支级一致率度量的是质量的 1-1 切片，恰是 M2M 分支
让渡之物（seed-42 的"四数据集全对"是运气，§5.6/§5.7 的相应声明据此撤回）。auto 四种子均值：
Douban 0.511±0.124、PeMS08 0.505——大幅劣于 oracle（0.639/0.658）。

**耦合集成（采纳为默认系统）**。三个分支的 Sinkhorn 耦合同尺度，直接平均后解码一次
（`--model ensemble`），无任何选择器：

| 系统（4 种子均值±std） | Douban | Cora | Airport | PeMS08 | 四集均值 |
|------|--------|------|---------|--------|---------|
| oracle（事后最优分支，不可实现） | 0.639 | 0.992 | 0.826 | 0.658 | 0.779 |
| auto（锚点仲裁） | 0.511±0.124 | 0.985±0.014 | 0.826±0.007 | 0.505±0.047 | 0.707 |
| **ensemble（耦合平均）** | **0.639±0.045** | **0.992±0.000** | 0.768±0.011 | **0.651±0.021** | **0.762** |

集成在 Douban/Cora/PeMS08 上**贴住 oracle**（真实组信号跨分支互相强化、虚假锐度互相稀释），
只在 Airport（单分支强主导）落后 0.058；四集均值 0.762 vs auto 的 0.707。方差也全面更小
（Douban 0.045 vs 0.124）。故事同时变简单：**训练三个变体、平均耦合、解码一次——没有仲裁器**。

## 5.9 扩面验证与适用边界（新增第五个数据集 + 划定前提）

把验证从 4 个数据集扩到全部 M2M 基准（规模探查见 `scripts/diagnose_rmt.py` 同法）。JOENA 的稠密
O(n²) 内存使 max(n)≤5200 可行，其余（acm-dblp、arxiv、dbp15k×3、ggi、flickr×2 等 max(n)~24000）
需稀疏/分块改造，暂缓。可行集里逐一验证，得到一条重要的**适用边界**：

**读出研究以"基座对齐器可用"为前提**。在 italy / phone-email / arenas 上，基座 JOENA 的节点级
`Hits@1 ≈ 0`（italy 0.000、phone-email 0.000、arenas 0.003），且**非训练不足**——加到 200 epochs
仍只有 italy 0.025 / arenas 0.011。这些是弱属性/无属性、结构近正则的图，JOENA 本就对不齐。此时 S 不
携带任何对齐信号，QuotientDecode 赖以工作的前提（组员 S 行共线）不成立，三分支的 MicroF1 全部塌到
0.05–0.15。这**不是读出失败，而是上游 1-1 对齐失败**，与本文机制正交。结论：**QuotientDecode 是 S 之上
的读出层，其适用前提是 S 有非平凡对齐信号（`Hits@1` 显著>0）；基座失败的数据集需先修基座**。可用作
一个廉价的前置守卫（测试锚点 Hits@1 阈值），落入低区即回退或告警，而非强行解码噪声。

**PPI：第五个有效数据集（分支紧簇体制）**。ppi（4577×4600，attr=50，Hits@1=0.970）基座健康。2 种子
（42/0）测得三分支挤在 0.84–0.85，且最优分支**跨种子翻转**（s42→joena 0.851、s0→pc 0.848）——并非
Airport 那样的单分支强主导，而是"分支近似等价"：

| 系统（2 种子均值） | MicroF1 |
|------|---------|
| joena | 0.848 | 
| joena-pc | 0.841 |
| joena-pc-gm | 0.843 |
| oracle（事后最优，翻转） | 0.850 |
| ensemble | 0.844（−0.005）|
| auto | 0.848（−0.001，vanilla 两次都近顶）|

**五数据集体制学**（读出研究的适用集）：
- **非平衡/重复密集**（Douban）：PC/GM 大胜，ensemble≈oracle，auto 崩（0.51）。
- **小平衡图**（PeMS08）：GM 大胜，ensemble≈oracle，auto 崩（0.51）。
- **大平衡强信号**（Cora / Airport）：vanilla 主导，ensemble 落后 0 / −0.058。
- **分支紧簇**（PPI）：三分支近等价，ensemble 与 auto 皆≈oracle（差 <0.005）。

**诚实的取舍**：没有哪个系统全域最优。ensemble 在"M2M 分支有用"的体制贴住 oracle 且方差最小，但在
vanilla/单分支主导时小幅让利（Airport −0.058、PPI −0.005）；auto 反之——vanilla 近顶时它选得准
（Airport/PPI），但在 M2M 体制会自信选错而崩（Douban/PeMS08 掉到 0.51）。**推荐 ensemble 为默认**
（最坏情况最好、无选择器），因为"何时该独用某分支"正是已证难的盲识别问题（§5.8）。Airport 型（单分支
强主导且能盲检测）仍是唯一有价值的未解缺口（§6-5）。

## 5.10 读出精修三方向（用户提议；配对多种子验证，一保留、一选项、一混合）

针对三条改进方向，全部实现为解码开关，在 **18 个 (数据集×种子) 缓存集成 S** 上做**配对**验证
（同一 S 只换读出，脚本 [`scripts/sweep_readout_variants.py`](../scripts/sweep_readout_variants.py)）：

**(a) 组级打分（mean 的稀释问题）**。实测四种方案（mean / max / sum / coverage）：
- **coverage（双向覆盖率）**：`score(A,B) = √(covA·covB)`，covA = A 成员质量落入 B 的平均占比，无标度、
  落在 [0,1]。配对 13/18 胜：**平衡体制真实更优**（Cora +0.0015×4 种子完全一致、PeMS08 全正
  +0.003~+0.025、PPI 全正），但 **Douban 四种子一致回退**（−0.007~−0.015：非平衡边际下列容量差 3×，
  行/列质量归一失真）。√(mean×coverage) 混合亦不两全（10/18）。
- 裁决：**默认保持 mean**；coverage 保留为平衡体制的文档化选项（`score_mode="coverage"`）；
  max / sum / hybrid 无净价值，**已删除**。
- 单测固化了 coverage 的反稀释性质：1-对-多正确块在 mean 下会输给错误单点、coverage 下不会
  （`CoverageScoreTest`）。

**(b) 商图邻居一致性（显式利用组级外部结构）**。`T ← (1−β)·T̂ + β·(Â_Q1 T̂ Â_Q2ᵀ)`——一致性原理
在商图层的回归（节点层它是错的，见主文档）。实测 β∈{0.1,0.2,0.4}：Douban +0.004~+0.006、PPI 微正，
但 PeMS08 −0.003~−0.008，overall 仅 +0.0006。**体制混合、量级小**：默认 β=0，保留为参数
（`neighbor_beta`），与 evict 组合时 Douban 可到 0.651（+0.012）但 PeMS08 代价更大。

**(c) merge-split 精修（可纠正的过合并）**。留一质心驱逐：成员对"组质心（去己）"余弦低于该侧合并
阈值则逐出为单点。第一版在 Cora 崩 −0.043——根因是**证据错配**（Cora 分区来自 attr 证据，驱逐却用
画像余弦，置换锁死下真成员画像本来就低）；修复为**仅在该侧分区来自 profile 证据时驱逐**后：
配对 **3 胜 0 负 11 平**（Douban s0 +0.021、PeMS08 s1 +0.005），纯增益。**已设为默认**（`evict=True`）。

**最终交付配置**（mean + evict，18 cells）：douban 0.6445 / cora 0.9916 / airport 0.7677 /
pems08 0.6518 / ppi 0.8444，overall **0.7800**（此前 0.7787）。

方向 (d)（组内不连通节点的通用发现，摆脱相邻/属性完全相同/生成规则依赖）未在本轮推进：已有测量表明
其信息瓶颈在表示侧（vanilla S 整行重复、邻居不相交拆分），通用化全局候选（如互 kNN 画像门控替代
精确属性桶）是下一步候选，需在 PC 类表示上验证。

## 6. 局限（如实）

1. **不连通天花板已被推进但未消除**：JOENA-PC 使 Douban 的全局候选复活（0.677），但零分布残尾仍在
   （q999≈0.999），且 ACS 略降（0.508→0.446）——全局合并换来的 MicroF1/MSF1 提升伴随少量误并。
2. **PC 的体制依赖**：平衡边际（Airport/PeMS08）上 PC 锐化 S、削弱画像可分组性，需靠 auto 仲裁退回基线——
   "一个 S 同时最优所有体制"仍未实现；对比项与边际约束的相互作用值得更细的训练侧研究。
3. **迭代收益小**（+0.004，airport 上甚至 −0.004）。
4. ~~单种子~~ → **已补 4 种子验证（§5.8）**，并据此撤回分支仲裁声明、换用集成。仍余：quick epochs、
   四数据集、λ 只在 Douban 粗调（其余三集为真泛化）、集成分支集固定为三。
5. **Airport 型缺口**：单分支强主导时集成被弱分支稀释（0.768 vs 0.826）——识别"何时该独用某分支"
   的盲信号即分支仲裁问题本身，已证难（§5.8）。
6. **锚点依赖**（分区层）：锚点 <20 或缺失时回落到对比度仲裁——在 Cora 型（画像退化）+无锚点的组合下
   会复现选错；彼时可用 §5.5 的谱指纹（erank/n 接近 1 ⇒ 不信画像）作无监督先验，尚未接入。

## 7. 下一步

1. ~~端到端 profile 对比损失~~ → **已落地为 JOENA-PC（§5.6）**，且证实主要收益来自输入对称破缺。
   其中"组级（邻域池化）softmax 对比项"**已测试并证伪（代码不保留，仅留此记录）**：把对比项的 logits 与
   正对挖掘用的耦合行按对侧一跳邻域池化（`softmax((z·Â₂ᵀ)/T)`），期望化解平衡边际下的锐化-可分组性张力。
   实测四数据集全败：Airport 0.757→0.760、PeMS08 0.418→0.434（仅轻微缓解，仍低于 vanilla 的
   0.831/0.447），且**摧毁了非平衡侧的增益**——Douban 0.677→0.458（池化模糊了全局候选依赖的行同一性
   信号）、Cora 0.993→0.938。教训：张力的根子在数据项的 Sinkhorn 边际，替身层的池化既救不了平衡侧、
   还污染行级证据。剩余方向：残尾 q999 的进一步溶解（更多负对/退火 λ）；平衡边际问题更可能需要动
   数据项本身（如训练时对目标侧做组级边际），而非对比替身。
2. ~~组级 unbalanced OT~~ → **已测试并证伪（代码不保留，仅留此记录）**。动机是过分割碎片应能共同匹配同一
   目标组（Hungarian 排他性禁止），实现为"每组一个单位质量 + KL 松弛边际"（POT `sinkhorn_unbalanced`，
   Douban-PC 的 S 上扫 reg∈{0.01,0.05} × reg_m∈{0.05…50} × 质量门槛{0.3,0.5}，共 14 个操作点）。
   结果：全操作面停在 MicroF1 **0.44–0.45 平台**（Hungarian 0.6768）；reg_m 越大（越接近排他）越好、
   单调逼近但不超越；对照组 greedy+共配合并 = 0.411 亦败。结论：**商图层的全局排他指派是承重结构**——
   §3-④"排他性放回正确层级"由"够用"升级为"在所试匹配器族中近乎最优"；低 reg_m 下质量销毁过于廉价导致
   大面积弃配是主要失效模式。
3. **谱指纹接入仲裁**：erank/n、GD 尖峰数作为无锚点时的证据先验（§6-6）。
4. **全量基准**：`run_m2m_experiments.py` 全 16 算法 × 全数据集，把 QuotientDecode(+auto) 作为统一读出层
   挂到每个 1-1 方法之上；多种子 + λ 敏感性，出终榜。
